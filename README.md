## 🎯 ที่มาของโปรเจกต์

Portfolio website นี้คือ **showroom ส่วนตัวของผม** — เป็นที่รวมผลงาน, ผลการแข่งขัน, และเรื่องราวการเรียนรู้ในสายเทคโนโลยีของ Kitsada Khamnuan

ทุกอย่างในเว็บนี้ผมเขียนเอง ไม่ใช้ Template สำเร็จรูป ตั้งแต่ Design System, Component Architecture, Animation Choreography, ไปจนถึง Performance Optimization — เพราะตัวเว็บเองก็คือ **ผลงานชิ้นหนึ่งที่อยากให้ผู้ดูประเมิน**

> 💡 **เป้าหมายการออกแบบ**
> - 🎨 ดูแล้ว "รู้สึก" — ไม่ใช่แค่อ่านผลงาน แต่ให้สัมผัสบุคลิกของผู้พัฒนาผ่าน Animation และ Detail
> - ⚡ โหลดเร็ว — Vite + Lazy Loading + Memo สำหรับทุก heavy component
> - 📱 ใช้ได้ทุกอุปกรณ์ — Mobile-first responsive ตั้งแต่ 320px ขึ้นไป
> - 🔍 SEO-aware — Title, meta, OG tags ทุกหน้า

## ✨ ฟีเจอร์เด่นของเว็บไซต์

### 🎬 Hero Section พร้อม Typewriter Effect
แสดงบทบาทแบบ Rotating — *Junior Software Engineer → Mobile Developer → Cybersecurity Enthusiast → AI Application Developer* — ทำให้ผู้เยี่ยมชมเห็นภาพรวมของทักษะได้ใน 5 วินาทีแรก

### 🎨 Dark Theme + Glass-morphism
Background `#020617` + Gradient ม่วง/ฟ้า + Frosted Glass Cards — สอดคล้องกับธีม Cybersecurity และ AI ที่เป็น niche หลัก

### 🃏 Featured Projects with Category Filter
แสดงผลงาน 6 ตัว พร้อม filter chips: **All · Cyber · AI · Mobile/Web · Game** — Smooth Animation ด้วย Framer Motion `layout` prop

### 📑 Dedicated Project Pages
แต่ละโปรเจกต์มีหน้าตัวเอง (`/cybersecurise`, `/boundless`, `/foodforyou`, `/scifare`) — แสดง Screenshots Gallery, Tech Stack, ฟีเจอร์, และ Story

### 🖼️ Full-screen Image Modal
คลิกรูปไหนก็ตามใน Project Page → ขยายเต็มจอ พร้อม Smooth Zoom Animation และ Body Scroll Lock

### 📄 PDF Resume/CV Viewer
แสดง Resume (TH/EN) และ CV ในตัว Modal บนเว็บ ไม่ต้อง Download — ใช้ `<embed>` ทับเลย

### 🏆 Credentials Pages
4 หน้าแยกสำหรับใบประกาศ: `/hackathon`, `/icpc2024`, `/ctf2024`, `/scirmutto`

### 🤖 Interactive AI Demo
หน้า `/ai-sms-detect` มี Live Demo ของ AI SMS Classifier — ผู้ใช้พิมพ์ข้อความได้, ดูผลทำนายจริง

### 📱 Responsive Navigation
Fixed navbar + Hamburger menu บน mobile + Smooth scroll-to-section

## 🎨 Design System

### 🌈 Color Palette

| Token | Hex | Usage |
|---|---|---|
| 🌌 **Background** | `#020617` | Main background (Slate-950) |
| 🔮 **Card** | `#0A0A0C` | Glass cards / panels |
| 💜 **Primary** | `#A855F7` | Purple — Hero, badges, CTA |
| 💎 **Secondary** | `#22D3EE` | Cyan — Accents, links, highlights |
| 🌟 **Accent (Gold)** | `#FFD700` | Boundless project, awards |
| 🟢 **Success** | `#27C93F` | Status indicators |
| ⚪ **Text Primary** | `#FFFFFF` | Main text |
| 🔘 **Text Muted** | `#9CA3AF` | Descriptions, captions |

### ✍️ Typography

- **Display:** System default with `tracking-tight` for hero text
- **Body:** Inter / system sans-serif
- **Monospace:** ฟอนต์ระบบสำหรับ tech labels และ code

### 🎬 Animation Patterns

| Pattern | Component | Library Feature |
|---|---|---|
| Fade-in on scroll | Featured Projects | `whileInView` |
| Layout shift on filter | Project grid | `layout` prop |
| Modal zoom | Image preview | `AnimatePresence` + `spring` |
| Page transition | Route changes | Initial `opacity`/`x` |
| Hover lift | Cards | `whileHover={{ y: -8 }}` |

## 🚀 Getting Started

### 📋 Prerequisites

- Node.js `>= 18.0.0`
- npm / pnpm / yarn
- Git

### 📥 Installation

```bash
# 1. Clone repository
git clone https://github.com/gong-sn-ix-ii/Portfolio.git
cd Portfolio

# 2. ติดตั้ง dependencies
npm install

# 3. รัน development server
npm run dev
# เปิด http://localhost:5173 ในเบราว์เซอร์
```

### 🛠️ Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | รัน Vite dev server (HMR) ที่ `localhost:5173` |
| `npm run build` | Compile TypeScript + Build production bundle ไปที่ `dist/` |
| `npm run lint` | รัน ESLint ตรวจ code style |
| `npm run preview` | Preview production build ที่ build ไว้แล้ว |

### 🚢 Deploy

เว็บนี้ deploy บน Custom Domain (`gong-ix-ii-dev.com`) — รองรับ deploy ได้หลาย platform:

```bash
# Vercel
vercel --prod

# Netlify
netlify deploy --prod --dir=dist

# Render / Hostinger / Cloudflare Pages
# → Build command: npm run build
# → Output directory: dist
```

## ⚡ Performance Optimizations

โปรเจกต์นี้ใส่ใจ Performance เป็นพิเศษ — เพราะคนเข้ามาดู Portfolio ครั้งแรกจะเด้งทันทีถ้าเว็บโหลดช้า

### 🚀 ที่ทำไว้แล้ว

| เทคนิค | ที่ไหน |
|---|---|
| ✅ **React.memo** | ทุก Project Page (Boundless, Cybersecurise, etc.) — ป้องกัน re-render |
| ✅ **Lazy Image Loading** | `loading="lazy"` + `decoding="async"` ในทุก Screenshot |
| ✅ **fetchPriority="high"** | LCP images (Hero mockups) — เร่งโหลดภาพหลัก |
| ✅ **WebP Format** | รูปทั้งหมดใช้ `.webp` ขนาดเล็กกว่า PNG/JPG ~30% |
| ✅ **Code Splitting** | Vite จัดให้อัตโนมัติ + Route-based splitting |
| ✅ **CSS Purging** | Tailwind purge unused classes ใน production |
| ✅ **Framer Motion `viewport={{ once: true }}`** | Animation รันครั้งเดียว ลด CPU |
| ✅ **Body Scroll Lock** | ตอนเปิด Modal ป้องกัน background scroll |

## 💡 บทเรียนจากการพัฒนา Portfolio นี้

### 🎨 Design > Decoration

ตอนแรกพยายามใส่ Animation ทุกที่ที่นึกออก — สุดท้ายเว็บดูรกและช้า ผมเรียนรู้ว่า **Animation ควรช่วยเน้น Hierarchy ของเนื้อหา** ไม่ใช่กลบมัน Cut animation ที่ไม่จำเป็นออกครึ่งหนึ่ง → ผลลัพธ์ดีขึ้นทั้ง UX และ Performance

### 🧩 Component Architecture สำคัญตั้งแต่วันแรก

โปรเจกต์ Portfolio เริ่มจาก "หน้าเดียว Home.tsx ยาว 2000 บรรทัด" 😅 — ตอน refactor เป็น Component แยกได้ จัดการง่ายขึ้นมาก แต่ใช้เวลาเยอะ บทเรียนคือ **ตั้งใจคิด component boundary ตั้งแต่ start** ไม่ใช่รอจน mess

### ⚡ TypeScript + Tailwind = Productivity Boost

TypeScript จับ error ตอน compile เยอะมาก (โดยเฉพาะตอน refactor props) Tailwind ทำให้ไม่ต้อง switch ไปไฟล์ CSS — เวลาทำ UI เร็วขึ้นเป็น 2 เท่า สอง stack นี้ผมเลือกใช้ในทุกโปรเจกต์เว็บหลังจากนี้

### 📱 Mobile-First ไม่ใช่แค่คำพูดสวย ๆ

Recruiter ส่วนใหญ่เปิด Portfolio จากมือถือ (ดูได้จาก Analytics) — ออกแบบ Desktop-first แล้วค่อยมา fix mobile จะลำบาก เริ่มจาก mobile ก่อนแล้ว Scale up ดีกว่ามาก
