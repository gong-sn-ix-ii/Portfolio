## 🎯 ที่มาของโปรเจกต์

Portfolio website นี้คือ **showroom ส่วนตัวของผม** — เป็นที่รวมผลงาน, ผลการแข่งขัน, และเรื่องราวการเรียนรู้ในสายเทคโนโลยี

## 💡 บทเรียนจากการพัฒนา Portfolio นี้

### 🎨 Design > Decoration

ตอนแรกพยายามใส่ Animation ทุกที่ที่นึกออก — สุดท้ายเว็บดูรกและช้า ผมเรียนรู้ว่า **Animation ควรช่วยเน้น Hierarchy ของเนื้อหา** ไม่ใช่กลบมัน Cut animation ที่ไม่จำเป็นออก ผลลัพธ์ดีขึ้นทั้ง UX และ Performance

### 🧩 Component Architecture สำคัญตั้งแต่วันแรก

เริ่มจาก "หน้าเดียว Home.tsx ยาว 2000 บรรทัด" 😅 — ตอน refactor เป็น Component แยกได้ จัดการง่ายขึ้นมาก บทเรียนคือ **ตั้งใจคิด component boundary ตั้งแต่ start** ไม่ใช่รอจน mess

### 📱 Mobile-First ไม่ใช่แค่คำพูดสวย ๆ

Recruiter ส่วนใหญ่เปิด Portfolio จากมือถือ ออกแบบ Desktop-first แล้วค่อยมา fix mobile จะลำบาก เริ่มจาก mobile ก่อนแล้ว Scale up ดีกว่ามาก
